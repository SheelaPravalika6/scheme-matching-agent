\# Government Scheme-Matching Assistant



An AI agent that helps users discover which government schemes they're eligible for, with transparent reasoning — not guesswork.



\## Problem Statement

Track A4 - Capabl Agentic AI Saksham Hackathon



\## How it works

1\. User answers a few quick questions (age, category, occupation, education)

2\. A rule-based eligibility engine checks their profile against 12 real government schemes

3\. An AI agent (Google Gemini) explains the results in plain language — why they qualify, or what's missing for a near-miss

4\. Required documents are shown for each matched scheme



\## Tech stack

\- Python, Streamlit (UI)

\- LangChain + Google Gemini (AI reasoning)

\- Custom rule-based eligibility engine (Python)



\## How to run

1\. Clone the repo

2\. `python -m venv venv` then activate it

3\. `pip install -r requirements.txt`

4\. Add your own `GOOGLE\_API\_KEY` to a `.env` file

5\. `streamlit run app.py`
